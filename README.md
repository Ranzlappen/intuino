# IntuiNO — Intuitively Wrong

An anti-UX satirical experience that teaches UX design principles through 10 increasingly chaotic levels. Learn what NOT to do in user interface design — the hard way.

[![ko-fi](https://ko-fi.com/img/githubbutton_sm.svg)](https://ko-fi.com/F1F1140LWT)

## Key Features

- **10 Progressive Levels of UX Chaos** — Each level ramps up the confusion
- **Boss Level** — The Final Chaos: everything at once
- **Chaos Engine** — 5-tier escalation with visual effects, fake crashes & fake updates
- **Achievements System** — 22 achievements to unlock
- **Procedural Audio** — All sounds synthesized via Web Audio API
- **Canvas Particle Effects** — Confetti, sparks, and chaos bursts
- **Easter Eggs** — Konami code, fake dev tools, secret "Perfect UX" mode
- **Neon / Glass-Card Aesthetic** — Looks great while being terrible to use
- **GSAP Animations** — Smooth transitions into madness
- **Responsive Design** — Bad UX on every screen size
- **Installable PWA** — Install the chaos on your device
- **Teaches Real UX Principles** — Jakob's Law, Fitts's Law, dark patterns, and more

## Tech Stack

- Vanilla HTML / JS (no framework, no build step)
- Tailwind CSS v3.4.1 (CDN)
- GSAP v3.12.5 (CDN)
- Google Fonts (Inter)
- Web Audio API (procedural sound synthesis)
- PWA (Workbox service worker)

## How to Use

Open `index.html` in any browser. Try to navigate through all 10 levels!

## Levels

| # | Level | UX Lesson |
|---|-------|-----------|
| 1 | Navigation Hell | Consistent navigation patterns (Jakob's Law) |
| 2 | Form Fiasco | Semantic color and form conventions |
| 3 | Gesture Gauntlet | Natural mapping in gestural interfaces |
| 4 | Button & CTA Chaos | Fitts's Law and label honesty |
| 5 | Settings Sabotage | Transparency and deceptive patterns |
| 6 | Modal Madness | Modal dialog best practices |
| 7 | Loading Screen Lunacy | Honest progress indicators |
| 8 | Notification Nightmare | Notification and attention respect |
| 9 | Dark Pattern Dungeon | Dark patterns and ethical design |
| 10 | THE FINAL CHAOS | Everything at once — empathy in design |
