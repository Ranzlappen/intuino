# IntuiNO — Intuitively Wrong

An anti-UX satirical experience that teaches UX design principles through 5 increasingly chaotic levels. Learn what NOT to do in user interface design — the hard way.

[![ko-fi](https://ko-fi.com/img/githubbutton_sm.svg)](https://ko-fi.com/F1F1140LWT)

## Key Features

- **5 Progressive Levels of UX Chaos** — Each level ramps up the confusion
- **Chaos Scoring & Achievements System** — Track your suffering
- **Deliberately Confusing UI Elements** — Educational by design
- **Neon / Glass-Card Aesthetic** — Looks great while being terrible to use
- **GSAP Animations** — Smooth transitions into madness
- **Responsive Design** — Bad UX on every screen size
- **Teaches UX Principles** — By showing you what NOT to do

## Tech Stack

- Vanilla HTML / JS
- Tailwind CSS v3 (CDN)
- GSAP v3.12.5 (CDN)
- Google Fonts (Inter)

## How to Use

Open `index.html` in any browser. Try to navigate through all 5 levels!
